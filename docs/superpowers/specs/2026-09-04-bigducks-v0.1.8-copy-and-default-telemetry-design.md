# BIG DUCKS LIVE v0.1.8 — telemetria padrão e textos diretos

## Objetivo

Publicar o `v0.1.8` com a telemetria Sentry ativada por padrão, sem coletar dados sensíveis, e tornar os estados do HUD mais diretos para o usuário.

## Decisões

- `telemetryEnabled` ausente em configurações antigas significa `true`; um `false` explícito continua permitindo desativação pelo HUD.
- O release continua enviando apenas eventos tipados, agregados e sanitizados. Nunca serão enviados IP, tokens, mensagens, URLs completas, caminhos, IDs Discord, SSRC ou logs.
- A telemetria mantém transporte HTTPS direto, fora do PAC/relay do Discord, e não instrumenta renderers.
- O rótulo `ESTADO DA ROTA` passa a `STATUS DA LIVE`; `Live protegida` passa a `Live liberada`; estados de falha deixam claro quando a live não está liberada ou está sem proteção.
- A ação principal passa a `Liberar live`; detalhes técnicos continuam disponíveis para diagnóstico.
- O release será `v0.1.8`, com bundle reproduzível, testes Go/Node, build Windows x64, SHA-256, assinatura Ed25519 e publicação no GitHub.

## Critérios de aceite

1. `DefaultConfig().TelemetryEnabled` é `true`.
2. Configuração sem `telemetryEnabled` carrega como ativada; `false` explícito permanece falso.
3. O HUD usa os textos diretos aprovados e mantém confirmação antes de desativar/apagar dados.
4. O bundle e o executável são gerados sem alterações não relacionadas.
5. `go test ./...`, `go vet ./...`, `npm run check:bridge` e `git diff --check` passam.
6. O release `v0.1.8` contém executável, manifesto e assinatura verificáveis.
