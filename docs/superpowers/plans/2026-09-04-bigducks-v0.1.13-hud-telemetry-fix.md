# BIG DUCKS LIVE v0.1.13 HUD and Telemetry Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Eliminate HUD content clipping/overflow and make the Electron bridge telemetry test work after Discord is ready.

**Architecture:** Keep the existing fixed landscape HUD and fit-to-monitor behavior, but increase its target client size and add a compact CSS layout for short work areas. Keep `@sentry/electron/main` in the bridge, disable its IPC integration because the bridge is initialized after `app.ready` and Discord already owns `sentry-ipc`, while retaining the direct Node HTTPS transport and no renderer instrumentation.

**Tech Stack:** Go/Windows WebView2, embedded HTML/CSS/JS, Electron CommonJS bridge, esbuild, Go tests, npm bridge checks.
