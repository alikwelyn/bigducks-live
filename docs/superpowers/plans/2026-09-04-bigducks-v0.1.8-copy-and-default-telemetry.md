# BIG DUCKS LIVE v0.1.8 — telemetria padrão e textos diretos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Publicar o `v0.1.8` com telemetria Sentry opt-in convertido em ativado por padrão e um HUD com estados de live mais diretos.

**Architecture:** O núcleo continuará sendo a autoridade da preferência: ausência do campo significa ativado, enquanto `false` explícito continua sendo respeitado. A bridge e o sanitizador existentes permanecem sem coleta sensível; somente os textos de estado e as mensagens de ação do HUD serão ajustados.

**Tech Stack:** Go 1.26, WebView2 HUD, JavaScript embutido, npm/esbuild, GitHub Releases, SHA-256 e assinatura Ed25519.

### Task 1: Tornar a telemetria ativada por padrão sem perder opt-out explícito

**Files:**
- Modify: `internal/app/config.go`
- Modify: `internal/app/config_test.go`

- [ ] **Step 1: Write failing tests**

Adicionar testes que diferenciem campo ausente de `false` explícito:

```go
func TestDefaultConfigEnablesTelemetry(t *testing.T) {
    if !app.DefaultConfig().TelemetryEnabled { t.Fatal("telemetry must be enabled by default") }
}

func TestLoadConfigWithoutTelemetryFieldEnablesIt(t *testing.T) {
    path := filepath.Join(t.TempDir(), "config.json")
    if err := os.WriteFile(path, []byte(`{"routingMode":"gateway"}`), 0o600); err != nil { t.Fatal(err) }
    config, err := app.LoadConfig(path)
    if err != nil { t.Fatal(err) }
    if !config.TelemetryEnabled { t.Fatal("missing telemetry field must use enabled default") }
}

func TestLoadConfigWithExplicitTelemetryFalseKeepsItDisabled(t *testing.T) {
    path := filepath.Join(t.TempDir(), "config.json")
    if err := os.WriteFile(path, []byte(`{"telemetryEnabled":false}`), 0o600); err != nil { t.Fatal(err) }
    config, err := app.LoadConfig(path)
    if err != nil { t.Fatal(err) }
    if config.TelemetryEnabled { t.Fatal("explicit false must disable telemetry") }
}
```

- [ ] **Step 2: Run focused tests and verify failure**

Run:

```bash

```

Expected: FAIL because the current default is false and the persisted field is a plain `bool`.

- [ ] **Step 3: Implement the default distinction**

Change `persistedConfig.TelemetryEnabled` to `*bool`, set `DefaultConfig().TelemetryEnabled = true`, and in `LoadConfig` use the pointer when present, otherwise retain the default. `SaveConfig` must continue writing a concrete boolean:

```go
TelemetryEnabled *bool `json:"telemetryEnabled"`
```

When loading:

```go

}
```

When saving, construct a local `telemetryEnabled := config.TelemetryEnabled` and assign its address to the persisted structure. Do not change `autoStartDiscord`, `disabled`, routing, proxy or recovery defaults.
